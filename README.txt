IMPORTANTE:
O script.js foi preservado em sua lógica de negócio. A única alteração funcional é a camada visual de renderização dos cards e a imagem do resumo.
Foram mantidos:
- preços e disponibilidade configurados no topo do JS;
- URL do Google Apps Script;
- envio para Google Planilhas;
- envio para WhatsApp;
- cálculo quantidade x dias x diária;
- formulário;
- máscara de telefone.

Para publicar:
1. Substitua os arquivos do seu site por index.html, style.css e script.js.
2. Copie a pasta assets inteira para o mesmo nível do index.html.
3. Não altere a URL do Apps Script no script.js.
